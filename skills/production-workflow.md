# Workflow
1. Brief: clarify goals, audience, output type, content inventory, assets, consent and acceptance.
2. Research: score reference metadata, verify links and licenses; extract patterns not pixels.
3. Design: hierarchy, grid, typographic scale, contrast, image direction, interaction rationale.
4. Build: semantic components, small dependencies, responsive states, reduced motion.
5. QA: typecheck, lint, unit test, build, Playwright widths and snapshots; manually inspect and run Lighthouse if available.
6. Delivery: record test environment, known issues, asset rights, deployment steps, client approval. Never deliver secrets.
