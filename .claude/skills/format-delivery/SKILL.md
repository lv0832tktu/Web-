# 指定フォーマット納品（Figma / Illustrator / Photoshop）

制作はこれまで通り HTML/CSS で行い、納品直前にこの手順で指定形式へ書き出す。ツールの詳細は `tools/export-formats/README.md`。

## 1. 要件を確認する（要件分析・納品担当）

依頼文から次を拾い、`brief` に書く。書かれていなければ推測と明記する。

- 納品形式: Figma / .ai / .psd / .svg / .pdf / .png のどれか（複数可）
- 寸法と解像度: px指定か、印刷（mm・dpi）か。印刷なら `--scale 2` 以上
- 編集の範囲: 文字を打ち替えたいのか、レイアウトごと触りたいのか
- フォント: 指定があるか。無ければ Google Fonts など無料で入手できるものを使う

形式ごとの納品物:

| 指定 | 納品するファイル |
|---|---|
| Figma | `.svg` を Figma に読み込んだファイル（または `.svg` ＋ `.png`） |
| Illustrator | `.ai`（＋編集用 `.svg`） |
| Photoshop | `.psd`（＋確認用 `.png`） |
| 元データ一式 | `.psd`・`.ai`・`.svg`・`.png` |

## 2. 制作時の注意（フロントエンド・モーション担当）

書き出し後も編集しやすくするため、指定形式がある案件では次を守る。

- 文字は画像にせず HTML の文字で組む。見出しの1文字分割アニメーションは使ってよい（書き出し時に1つの文字レイヤーにまとまる）
- 図形はなるべく単色＋角丸＋実線の枠で作る（ベクターのまま書き出される）。グラデーション・影・ぼかしは画像レイヤーになる
- 作品の外枠には `data-artboard` を付け、`?size=WxH` で寸法を切り替えられるようにする（テンプレートの方式）
- アニメーションは最終状態が完成デザインになるように作る

## 3. 書き出す

```bash
cd tools/export-formats && npm install   # 初回のみ
node export.mjs <作品.html> --size 1080x1350 --out ../../delivery/<案件名>/
```

ページ全体（LP・サイト）は `--size` の代わりに `--width 1440`（スマホ版は `--width 390`）。

## 4. 確認する（QA・デザイン審査担当）

- `manifest.json` の `checks.svgVsPng.mean` と `checks.pdfVsPng.mean` が 0.97 以上
- `notes` に画像化された文字があれば、編集が必要な文字でないか確認。必要なら効果を外して作り直す
- `<名前>.svg-preview.png` と `<名前>.png` を見比べ、ずれ・欠けがないか目視確認
- `fonts` の一覧を納品メモに書く

## 5. 納品メモに書くこと

- 使用フォントと入手先（例: Noto Sans JP — Google Fonts）
- PSD を開いたときに「テキストレイヤーを更新」と出たら「更新」を押すこと
- `.ai` は PDF 互換形式であること（Illustrator でそのまま開ける。必要なら「別名で保存」でネイティブ形式にできる）
- 画像として配置した部分（グラデーション・写真など）

納品（外部への送付）は人間の承認を得てから行う。
