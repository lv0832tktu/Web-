# Claude Design 自動切り替え

見た目を提案・比較・修正する工程では、HTMLファイルやスクリーンショットだけで返さず、
**Claude Design キャンバス**（Artifact の Design タイプ）にアートボードとして並べる。
ユーザーが「Claude Designで」と言わなくても、下の「使う場面」に当たれば自動で使う。

## 使う場面

| 場面 | キャンバスでやること |
|---|---|
| 案出し（初回） | 方向性の違う3案を1つのキャンバスに横並び。各案のアートボード名は「A案 ナチュラル」のように短く |
| バナー・SNS・サムネイル | 指定サイズ（例 300×250, 1080×1080）のアートボード。複数サイズ展開は同じ案を1行に並べる |
| LP・HP | PC幅1440のページ（`expand: "fill"`）。必要ならSP幅390を同じ行に追加 |
| UI/UX | 画面ごとに1アートボード（スマホ390×844、PC 1440）。操作できるモックは `is_interactive: true` |
| 修正依頼 | **同じキャンバスのURLを更新**。新しいキャンバスは作らない。変更点だけ直す |

使わない場面: 文章だけの相談、コードの不具合修正、納品ファイルの書き出し。

## 手順

1. **キャンバスがあるか確認する。** 案件フォルダの `projects/<案件>/design-links.md` か、スレッドの過去のやり取りにURLがあればそれを使う。
   プロジェクト内の既存キャンバスは `list_project_artifacts` でも探せる。
2. **なければ作る。** `Artifact` ツールで `action: "quickstart"`, `intent: "design"` を呼び、返ってきた Design タイプの `type_url` で
   `title`（例「さくら歯科 LP デザイン案」）と `auto_open: "after_first_write"` だけを付けて publish する。
   以降は返ってきた `url` だけを使う。作成結果に入っているタイプの指示（SKILL.md）に必ず従う。
3. **素材を決める。** 配色・書体・構成は `BRIEF.md`（`tools/new-project.mjs` が作るもの）やレシピDBの結果を使う。
   画像が必要なら `image-generation` スキルで作り、キャンバスにはアセットとしてアップロードして `/_blob/...` のURLで参照する（data URIは使わない）。
   まだ画像がない場所は「[メイン写真]」のようなラベル付きプレースホルダーにする。
4. **書き込む。** 作業フォルダはスクラッチパッドの中に1つ作り、`project/canvas.json` と `project/<名前>.dc.html` を置いて送る。
   1枚目は `Main.dc.html`。3案なら `A.dc.html` `B.dc.html` `C.dc.html` を横に80pxずつ空けて並べ、上に `title1` のノートで案件名を置く。
   1ファイル書いたら送る、を繰り返す。
5. **記録する。** キャンバスのURLを `projects/<案件>/design-links.md` に追記する（案件フォルダがまだなければスレッドの返信に書く）。
6. **返信する。** キャンバスのリンクと、各案の狙いを1行ずつ。案の説明はアートボードの中ではなく返信に書く。

## デザインの守りごと

- ダミーの実績・数字・お客様の声は入れない。未確定の情報は「[料金]」のようなプレースホルダーにする。
- 色はBRIEFのトークン（`--c-primary` など）の値を使う。和文2種＋欧文1種まで、Google Fonts のみ。
- 文字のコントラスト4.5:1以上、タップ領域44px以上。ボタンは本物の `<button>` / `<a>`。
- 参考サイトの複製はしない。レシピDBは設計図として使い、クライアント固有の要素を3つ以上入れる。

## キャンバスが使えない環境のとき

Codex やローカル環境など `Artifact` ツールがない場合は、今までどおり `projects/` にHTMLを作り、
`node tools/render.mjs <html> --sizes ...`（ある場合）で画像を書き出して `designs/<案件>/` に置く。そのことを返信で一言伝える。

## 共有と承認

キャンバスは作成時は非公開。クライアントへのリンク共有・外部ツール（Canvaなど）への送信は、人間が承認してから行う。
