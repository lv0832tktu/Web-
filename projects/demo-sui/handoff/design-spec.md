# Design Spec
Identity: calm, organic, refined. Colors: forest #244b3e, cream #f5f2e9, terracotta #aa6746. Typography: DM Sans + Noto Sans JP. Layout: hero split on desktop, stack mobile; editorial sections. Motion: reveal with IntersectionObserver, graceful fallback, reduced-motion support. Product images are CSS illustrations, explicitly fictional. CTA: anchor links.
