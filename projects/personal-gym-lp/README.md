## デザイン方針
- 「ストイックすぎない、はじめてでも踏み出せる」を軸に、白と生成りの余白＋深いグリーン（信頼・清潔感）＋オレンジのCTA（行動）。
- 書体: Zen Kaku Gothic New（見出し）／Noto Sans JP（本文）／Outfit（英字・数字）。すべて Google Fonts で無料入手可。
- CTAは FV・流れの直後・最終セクションの3か所＋ヘッダー。ボタンの下に「所要約60分／勧誘なし」など不安を下げる一言。

## 仮のもの（クライアント情報に差し替え）
- 写真: 緑灰色の「PHOTO」枠すべて。Before/After と利用者の声の写真は、必ずご本人の許可を得た実写に差し替え。
- `[ ]` で囲んだ文字: ジム名・ロゴ、トレーナー名・資格、料金、店舗情報、FAQの一部回答。
- 利用者の声: 見出し・本文とも枠のみ（「サンプル」ラベル付き）。架空の声は入れていません。
- 特徴コピー（完全個室・ウェア無料貸出・LINE食事サポート・勧誘なし・24時間Web予約など）: 一般的な例として入れています。実際のサービス内容と合うか確認が必要です。
