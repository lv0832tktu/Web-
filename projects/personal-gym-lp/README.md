## 写真について（AI生成の仮素材）
FV・コンセプト・トレーニング・食事・最終CTAの5枚は、Higgsfield の z_image で生成した仮素材です。写真の右下（FVは右上）に「イメージ」と表記しています。
実在のスタッフやお客様として見せないよう、公開前にクライアントの写真へ差し替えるか、「イメージ」表記を残してください。
生成の記録（プロンプト・モデル・日時）は `projects/personal-gym-lp/design/assets/ledger.jsonl` にあります。
