# 配色ガイド

DBの全レシピは「スタイル別に検証済みの80パレット」から配色しています（`tools/taxonomy/common.mjs`）。
自分で配色を作るときも、このページのルールで作ればプロの配色になります。

## 役割で色を決める（CSS変数）

| 変数 | 役割 | 面積 |
|---|---|---|
| `--c-bg` | ページの背景。純白(#FFF)より少し色味のある白（#FAFAF7等）が上品 | 70% |
| `--c-surface` | カード・セクション背景。bgより一段濃い（or 白） | — |
| `--c-text` | 文字。純黒(#000)ではなく、primaryに寄せた濃い色（#1A1A2E等） | — |
| `--c-primary` | ブランドカラー。見出しの強調・リンク・アイコン | 25% |
| `--c-accent` | CTA・割引・重要数字。primaryの補色か、明度差の大きい色 | 5% |
| `--c-on-primary` | primary/accent の上に乗る文字色（白 or 黒をコントラストで自動選択） | — |

## コントラスト（必須）
- 本文：4.5:1 以上 ／ 大きな見出し・ボタン：3:1 以上（WCAG 2.1 AA）
- `node tools/check.mjs` が tokens.css から自動計算します

## 業種別の色の印象
| 色 | 印象 | 向いている業種 |
|---|---|---|
| 青・紺 | 信頼・誠実・知性 | 金融、士業、BtoB、医療、IT |
| 緑 | 安心・自然・健康 | 医療、食品、農業、環境、歯科 |
| 赤 | 情熱・緊急・食欲 | セール、飲食、スポーツ、エンタメ |
| オレンジ | 親しみ・元気・行動 | CTA、教育、子ども、引越し |
| 黄 | 注意・楽しさ・安さ | セール、キッズ、注意喚起 |
| ピンク | 優しさ・女性・恋愛 | 美容、ウェディング、コスメ |
| 紫 | 高貴・神秘・個性 | 占い、美容医療、エンタメ |
| 黒・金 | 高級・権威 | 高級ホテル、不動産、美容医療 |
| ベージュ・くすみ | 上品・ナチュラル | サロン、カフェ、雑貨、住宅 |

## 配色テクニック
- **ドミナントカラー**：全体を1色相でまとめ、明度だけ変える（上品）
- **補色アクセント**：primaryの反対色をCTAにだけ使う（目立つ）
- **トーンオントーン**：同系色の濃淡（ナチュラル・北欧）
- **グラデーション**：2色の色相差は60°以内が綺麗。中間を `color-mix()` で作るとにごらない
- **ダークモード**：背景は#000でなく#0B0D12程度、面は明度を上げて階層を作る

## CSS で色を派生させる
```css
background: color-mix(in srgb, var(--c-primary) 12%, transparent); /* 薄い背景 */
border-color: color-mix(in srgb, var(--c-text) 10%, var(--c-bg));  /* 罫線 */
box-shadow: 0 8px 24px color-mix(in srgb, var(--c-primary) 35%, transparent); /* 色付きの影 */
```
