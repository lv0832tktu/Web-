# コピーライティング ガイド（デザイナー向け最小限）

デザインの品質は「文字」で半分決まる。クライアントから原稿が来ない時、この型で仮コピーを作る。

## キャッチコピーの型
| 型 | 例 |
|---|---|
| ターゲット＋ベネフィット | 30代の乾燥肌に、朝まで続くうるおいを。 |
| 数字で具体化 | 3ヶ月で−5.2kg。続けられるオンラインジム。 |
| 問いかけ | その肩こり、枕のせいかもしれません。 |
| 損失回避 | 知らないと損する、確定申告の3つの控除。 |
| ビフォーアフター | 「何から始めれば？」が「明日からこれをやる」に。 |
| 権威 | 歯科医師が開発した、子どものための歯ブラシ。 |
| 限定性 | 今月末まで、初月0円。 |
| 意外性 | 実は、毎日の洗顔が乾燥の原因でした。 |

## CTA（ボタン）の文言
「動詞＋得られるもの」。×送信する ×詳しくはこちら → ○無料で資料をもらう ○30秒で予約する ○自分に合うプランを診断する
ボタンの上か下に **マイクロコピー**（「しつこい営業はしません」「1分で完了」「カード登録不要」）。

## 文字量の目安
- バナー300×250：キャッチ8〜12字＋サブ15字＋CTA
- YouTubeサムネ：3〜8字（2行まで）
- LP FV：キャッチ20字以内＋リード60字以内
- 見出し：15〜25字 ／ 本文1段落：100〜150字

## 表記ルール
- 数字は半角、3桁区切り（12,000）。単位は全角（人・件・円）
- 「！」は1画面1つまで。「〜」より「—」の方が洗練されて見える
- 英字ラベルは大文字＋字間広め（`letter-spacing: .2em`）

## 法律（必ず守る）
- **景品表示法**：根拠のない「No.1」「最安」「業界初」はNG。根拠（調査機関・期間）を注記
- **薬機法**：化粧品・健康食品で「治る」「痩せる」「シミが消える」はNG
- **医療広告ガイドライン**：ビフォーアフター写真は治療内容・費用・リスクの併記が必要
- 「効果には個人差があります」を数字の近くに
