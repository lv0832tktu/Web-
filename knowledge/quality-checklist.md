# 納品前クオリティチェックリスト

自動チェック: `node tools/check.mjs projects/<案件> --browser`（エラー0必須）。以下は目視チェック。

## デザイン
- [ ] **視線誘導**：最初に見る場所→次→CTA の3段階が明確か
- [ ] **情報の優先順位**：一番伝えたいことが一番大きく、強いか
- [ ] **揃え**：全要素が見えない線に揃っているか（左右の端・テキストの頭）
- [ ] **余白**：8の倍数で、グループ内<グループ間になっているか
- [ ] **色数**：ベース70 / メイン25 / アクセント5。tokens.css 以外の色を使っていないか
- [ ] **フォント**：和文2＋欧文1まで。数字は欧文書体か
- [ ] **ジャンプ率**：見出しと本文の差が十分か（2倍以上）
- [ ] **写真のトーン**が揃っているか。粗い画像・引き伸ばし画像がないか
- [ ] **動き**：情報理解を助けているか（同時に動くもの2つまで）／速度が統一されているか

## 文章
- [ ] 誤字脱字（クライアント名・電話番号・価格は2回確認）
- [ ] テンプレートのダミー文言（Lumi Fit / KINARI / 山田 花子 / 0000）が残っていない
- [ ] 景品表示法・薬機法に抵触する表現がない／数字に根拠・注釈がある
- [ ] 改行位置が自然（スマホで1文字だけの行がない）

## 技術
- [ ] PC 1440 / タブレット 768 / スマホ 375 で崩れがない、横スクロールが出ない
- [ ] すべてのリンク・ボタン・フォームが動く（フォームの送信先を設定したか）
- [ ] 画像に alt、width/height。WebP・適切なサイズ（400KB以下目安）
- [ ] title / description / OGP / favicon
- [ ] キーボード（Tab）で操作でき、フォーカスが見える
- [ ] 効果音にON/OFFがある、`prefers-reduced-motion` で動きが止まる
- [ ] Chrome / Safari（iPhone）で確認

## バナー
- [ ] 入稿規定（サイズ・容量150KB等・ループ3回/30秒以内・枠線）
- [ ] 50%縮小で読めるか
- [ ] 最終フレームで全情報が見えるか
- [ ] 全サイズで要素の優先順位が同じか

## 納品物
- [ ] `delivery/<案件>/` に制作物＋ README.txt
- [ ] 使用フォント・素材のライセンス表記
