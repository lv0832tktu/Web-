# 参考ギャラリーサイト（研究用リンク集）

実在の優れたデザインを見て「目を肥やす」ためのリンク集です。
**ここにある作品のデザイン・画像・文章をコピーして納品してはいけません**（著作権侵害）。
見るべきは「なぜ良いのか」＝レイアウト・余白・配色比率・書体の組み合わせ・動きのタイミング。
※URLは作成時点のものです。サイト側の移転・閉鎖でリンク切れの場合は名前で検索してください。

気づいたパターンは `tools/taxonomy/*.mjs` に追加して `npm run build:db` すれば、DBのレシピに反映されます。

## 研究のしかた（1サイト5分）
1. スクショを撮り、要素を「見出し・本文・ボタン・写真・余白」に色分けして面積比を見る
2. 使われている書体と、見出し/本文のサイズ比（ジャンプ率）をメモ
3. 配色を5色に分解して `bg / surface / text / primary / accent` に当てはめる
4. 動きの「種類・時間・順番」をメモ（DevTools → Animations パネル）
5. 「自分の案件ならどう応用するか」を1行で書く
