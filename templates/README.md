# Templates
`index.html` + `src/` is a runnable LP starter. Copy into a project and replace brand, copy, illustration, tokens and interaction deliberately. Do not blindly reuse SUI artwork. Corporate, recruiting, EC and app templates are **not implemented**.

案件のヒアリング・仕様・受入条件は `handoff/` の日本語テンプレートを使う。実在案件の原稿、素材権利、CTA、納期、修正範囲を決めてから制作する。未記入テンプレートは完成済みの要件書ではない。
