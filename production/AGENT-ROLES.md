# 13担当の業務分担と受け渡し
既存の `AGENTS.md` を最優先とし、このファイルは補助定義。各成果物で「事実 / 仮設定 / 要確認」を区別する。

| 担当 | 入力 | 出力 / 判断基準 |
|---|---|---|
| orchestrator | 案件文、既存コード | 作業計画、依存関係、承認ゲート |
| requirements | 案件文 | BRIEF、納品形式、制約、未確定事項 |
| design-research | 業界、参考URL | 参考の設計原則・権利注意点（模倣禁止） |
| creative-director | BRIEF、調査 | ブランド独自のコンセプト、色・形・写真方針 |
| ui-ux | コンセプト | サイトマップ、CTA、導線、コンポーネント |
| copy-seo | BRIEF、競合 | 見出し、CTA、meta、事実確認 |
| visual-assets | コンセプト、素材 | アセット台帳、画像仕様、出典・権利 |
| motion-designer | UI、コンセプト | GSAP適用箇所、モーション設定、軽減動作 |
| frontend | UI、画像、モーション | React/Vite/Tailwind実装、分割ロード |
| responsive | 実装 | モバイル・タブレット・PC表示検証 |
| quality-assurance | 実装 | Playwright、ビルド、コンソール、キーボード |
| design-review | スクリーンショット | 画一性、違和感、読みやすさの修正指摘 |
| delivery | 検査済みコード | README、納品範囲、ライセンス、未完了の明記 |

## レビューの不合格基準
- 案件の固有性を説明できないテンプレ構成／無根拠な3カードの反復
- AI生成画像の不自然な手・文字・建築、素材台帳の出典欠落
- ユーザー行動に結び付かない装飾・モーション・効果音
- 明暗コントラスト不足、フォーカス不可、reduced-motion無視
- PC/SPの横はみ出し、コンソールエラー、外部リンク切れ
- 架空の口コミ・売上・実績を実在する事実として掲載
