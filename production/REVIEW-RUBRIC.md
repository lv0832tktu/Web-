# 納品前デザインレビュー

自動検査の合格だけで独自性や権利を保証しない。13担当のdesign-reviewが画面を見て記録する。

| 観点 | 不合格の兆候 | 合格の証拠 |
|---|---|---|
| ブランド固有性 | ブランド名の差し替えだけで成立する | 固有要素3点とUI・写真・コピーへの反映を説明 |
| 構成 | 理由のない中央見出し・3カードの反復 | 各節の目的と情報優先度が要件に結び付く |
| 素材 | 不自然な手・文字・建築、画像間の製品不一致 | 拡大目視と素材台帳の確認者・結果 |
| 装飾 | 内容に無関係な3D・グラデーション・効果音 | 演出が理解や行動をどう助けるか説明 |
| 読みやすさ | 文字の重なり、弱いコントラスト | 3端末の画面確認、拡大・フォーカス確認 |
| 誠実さ | 仮の実績・口コミが事実に見える | 原文・公開情報との照合、仮設定の明示 |
| 利用権利 | 出典・許諾が不明 | assets.jsonの権利・改変可否・確認記録 |

REVIEW.mdに「画面・問題・根拠・優先度・修正・再確認」を記録。品質を数値で自動保証せず、重大指摘が残る間は納品不可。

自動検査: check-assetsは台帳漏れ・未確認・ファイル不存在・容量を検出。Playwrightは画面幅・リンク・画像・コンソール等を検査。外部リンクのHTTP状態、コントラスト、スクリーンリーダー、画像品質は追加の目視・手動確認が必要。
