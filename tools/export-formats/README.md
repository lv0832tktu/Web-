# 指定フォーマット書き出し（Figma / Illustrator / Photoshop）

HTMLで制作した作品（バナー・SNS投稿・サムネイル・LP・サイト）を、クライアント指定の形式で納品できるように書き出すツールです。
Figma・Illustrator・Photoshop を持っていなくても、各アプリで**レイヤーを分けたまま開いて編集できるファイル**を作れます。

## 使い方

```bash
cd tools/export-formats
npm install                      # 初回のみ

# バナー・SNS投稿など（サイズ指定のあるテンプレート）
node export.mjs ../../projects/案件名/banner/index.html --size 1080x1350

# LP・サイト（ページ全体）
node export.mjs ../../projects/案件名/site/index.html --width 1440

# 形式を絞る・2倍解像度にする
node export.mjs 作品.html --size 1200x628 --formats psd,ai --scale 2
```

出力先は既定で `<作品のフォルダ>/export-formats/<名前>/` です（`--out` で変更）。

| オプション | 内容 |
|---|---|
| `--size 1080x1350` | アートボードの寸法。テンプレートの `?size=` に渡されます |
| `--query "slide=2"` | 追加のURLパラメータ（カルーセルの2枚目など） |
| `--selector ".ab"` | 書き出す要素。既定は `[data-artboard]`、無ければページ全体 |
| `--width 1440` | ページ全体を書き出すときの画面幅（スマホ版は `--width 390`） |
| `--formats svg,psd,ai,pdf,png` | 出力形式（既定: すべて） |
| `--scale 2` | 倍率。印刷物や高解像度指定のときに使います |
| `--psd-text raster` | PSDの文字を画像レイヤーにする（既定は編集できる文字レイヤー） |

## 出力されるファイルと、クライアントでの開き方

| ファイル | 指定アプリ | 開き方 | 中身 |
|---|---|---|---|
| `.svg` | **Figma** | Figma のキャンバスにドラッグ＆ドロップ | 図形・文字・画像がレイヤーとして分かれた状態。文字はそのまま打ち替えられます |
| `.svg` | **Illustrator** | ファイル → 開く | 同上。レイヤー名は要素名（`T_` は文字、`BOX_` は図形、`IMG_` は画像、`FX_` は装飾） |
| `.ai` | **Illustrator** | ファイル → 開く | PDF互換のAIファイル。見た目の再現性が最も高い（グラデーション等もベクターのまま） |
| `.psd` | **Photoshop** | ファイル → 開く | 要素ごとのレイヤー＋編集できる文字レイヤー。重なり順も元のデザイン通り |
| `.pdf` | 共通 | どのアプリでも | `.ai` と同じ内容 |
| `.png` | 確認用 | — | 完成見本 |
| `manifest.json` | — | — | 使用フォント・レイヤー数・再現度チェックの結果 |

### 案件ごとの納品の組み合わせ（目安）

- **「Figmaで納品」** → `.svg` を Figma に読み込み、そのFigmaファイルを共有（または `.svg` と `.png` を納品）
- **「Illustrator（.ai）で納品」** → `.ai`（＋編集用に `.svg`）
- **「PSDで納品」** → `.psd`（＋確認用 `.png`）
- 形式の指定が「元データ一式」なら、`.psd`・`.ai`・`.svg`・`.png` をまとめて納品

## 仕組み

1. 作品をブラウザ（Playwright）で開き、アニメーションを最終状態で止めます。
2. 要素を1つずつ調べ、背景・枠・画像・装飾・文字の段落に分解し、元のデザインと同じ重なり順に並べます。
3. 単色の図形（角丸・枠線を含む）と文字は**ベクター・編集できる文字**として、写真・グラデーション・影などは**その要素だけを描いた画像**として取り込みます。回転した要素も角度を保ちます。
4. 書き出したSVGとPDFをもう一度画像にして完成見本と比べ、**再現度**を `manifest.json` に記録します（目安: 97%以上）。

## 納品前のチェック

- [ ] `manifest.json` の再現度が SVG・PDF とも 97% 以上か
- [ ] `manifest.json` の `fonts` に書かれたフォントを確認し、クライアントに伝えたか（Google Fonts なら無料で入手できます）
- [ ] `notes` に「画像として配置」と書かれた文字があれば、編集が必要な箇所かどうか確認したか
- [ ] 可能なら実際のアプリ（または無料の Photopea / Figma 無料プラン）で開いて確認したか

## 注意点・制約

- **PSDの文字レイヤー**: Photoshop で開くと「テキストレイヤーを更新しますか」と表示されます。**「更新」を押してください**（フォントがインストールされていれば元通りに描き直されます。「いいえ」を押すと文字レイヤーが正しく表示されません）。この確認を出したくない場合は `--psd-text raster` で文字を画像レイヤーにできます。納品メモにひとこと添えると親切です。
- **フォント**: 各アプリはパソコンにインストールされたフォントを使います。未インストールだと別のフォントに置き換わります。PSDのフォント名は Google Fonts の命名規則（例: `NotoSansJP-Bold`）から推定しています。
- **AIファイル**: Illustrator 独自の保存形式ではなく、PDF互換の `.ai` です（Inkscape などの「AI形式で保存」と同じ方式）。Illustrator でそのまま開けます。クライアントがネイティブ形式を強く求める場合は、Illustrator で開いて「別名で保存 → Illustrator (.ai)」すれば完全なネイティブ形式になります。
- **画像になる要素**: グラデーション・影・ぼかし・グラデーション文字・波線の下線・canvas の描画などは、見た目を崩さないため画像として取り込みます（Figma/Illustrator/Photoshop 上で移動・差し替えはできます）。
- **動き（アニメーション）**: 静止画の形式なので、最後の状態で書き出されます。動画やGIFが必要な場合は別途 `tools/render.mjs`（自動化システム側）を使います。
- **ページ全体のPDF/AI**: 印刷時にレイアウトが変わらないよう、レイヤー化したSVGを元に作ります。縦19,000px程度を超えるページは途中で切れるため、セクションごとに `--selector` で分けて書き出してください。
- **Figma**: `.fig` ファイルを直接作ることはできません。SVG を読み込むと編集できる Figma のレイヤーになります。

## テスト

```bash
npm test   # sample/banner.html を全形式に書き出し、ファイル・レイヤー・再現度を検査
```

PDF/AI の再現度チェックには `pypdfium2`（`python3 -m pip install pypdfium2`）か `pdftocairo`（poppler）を使います。どちらも無い場合はチェックだけ省略されます。
